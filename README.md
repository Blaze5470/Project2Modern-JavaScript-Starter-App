# Web Scripting 2 Portfolio Starter

A Vite-powered starter project for Web Scripting 2.

## Run locally

```bash
npm install
npm run dev
```

## Create a production build

```bash
npm run build
```

## Preview the production build

```bash
npm run preview
```

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- npm
- Vite
- JavaScript modules
